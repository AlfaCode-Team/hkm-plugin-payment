MarzPay Cursor Skill
====================

1. Copy this entire `marzpay-integration` folder into your project:

   .cursor/skills/marzpay-integration/

2. The skill file is SKILL.md inside this folder.

3. In Cursor, ask your agent to integrate MarzPay — it will use this skill automatically.

4. Set environment variables in your app (see SKILL.md).

5. Full docs: see the MarzPay documentation site linked when you downloaded this file.
